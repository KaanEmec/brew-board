# Job: package list and navigation

## Objective
Let a user quickly see what is installed and what needs attention.

## Tasks
- Build a keyboard-first list of installed formulae and casks with an outdated indicator.
- Add search, filtering by type/status, and predictable selection/navigation.
- Show a small status area with inventory counts, loading state, and shortcut hints.
- Adapt the layout to narrow terminals and terminals without color.

## Expected outcome
A user can launch Brew Board, find a package, and identify outdated items without knowing Homebrew command syntax.
