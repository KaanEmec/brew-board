# Job: package details

## Objective
Give enough package context for a user to decide whether to maintain it later.

## Tasks
- Add a details view for the selected item: name, type, installed/available version, and description when available.
- Show the source and limitations of the data rather than filling missing fields with guesses.
- Make returning to the list and retaining the search/filter state straightforward.
- Keep all actions read-only in this version.

## Expected outcome
A user can inspect a package and return to the same place in the inventory without accidental changes.
