# Job: verify the inspection preview

## Objective
Confirm the first release is useful, responsive, and truly read-only.

## Tasks
- Test empty, small, and large inventories using fixtures and a real macOS Homebrew installation.
- Exercise formulae, casks, outdated packages, search, filters, refresh, narrow terminals, and no-color output.
- Confirm no package-changing Homebrew commands run during launch, navigation, or refresh.
- Document installation, navigation, supported Homebrew behavior, and known limitations.

## Expected outcome
The preview gives a reliable package view and its repository contains reproducible checks and basic usage instructions.
