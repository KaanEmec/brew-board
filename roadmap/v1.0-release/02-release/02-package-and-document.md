# Job: publish the 1.0 release

## Objective
Make Brew Board straightforward to install, inspect, and use safely.

## Tasks
- Provide a macOS binary and documented installation path with a checksum.
- Write a concise quick start, keyboard reference, plan/confirmation example, and receipt example.
- Add licence, release notes, limitations, and troubleshooting guidance.
- Verify the release artifact on a clean macOS account or machine where practical.

## Expected outcome
A tagged 1.0 release can be installed by a new user who understands exactly when Brew Board will change packages.
