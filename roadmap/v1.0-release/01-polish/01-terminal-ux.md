# Job: polish terminal behavior

## Objective
Make routine maintenance comfortable across ordinary terminal sizes and input conditions.

## Tasks
- Review key bindings, focus, search behavior, confirmation wording, and visible progress with real users or realistic walkthroughs.
- Handle resize, small terminals, no-color mode, long package names, and large output streams.
- Make errors and recovery paths visible without burying the active task.
- Check memory and responsiveness against a large fixture inventory.

## Expected outcome
The core flow remains legible and responsive in realistic terminal environments.
