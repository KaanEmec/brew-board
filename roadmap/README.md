# Brew Board roadmap

| Version | Outcome | Epics |
|---|---|---|
| [v0.1 — inspect](v0.1-inspect/) | Read-only, keyboard-first package and update view. | Homebrew adapter, TUI inspection, validation |
| [v0.2 — maintenance session](v0.2-maintenance-session/) | Stage, preview, execute, and review explicit operations. | Stage and preview, execution, receipt |
| [v1.0 — release](v1.0-release/) | Polished, tested macOS distribution. | Polish, release |

Within each epic, run numbered job files in order. A later version depends on the preceding version's verified outcome. The expected outcome in each job is its completion check; version names are targets, not claims that anything has shipped.
