# Job: maintenance receipt and cleanup choice

## Objective
End each session with a useful account of what changed and what still needs attention.

## Tasks
- Summarize selected items, executed commands, observed version changes, failures, and pending work.
- Offer a copyable or saveable local text receipt without collecting telemetry.
- If cleanup is included, show it as a separate reviewed operation with its exact command and confirmation.
- Display follow-up guidance for errors without claiming to have diagnosed Homebrew internals.

## Expected outcome
A user can understand the session result later, and cleanup never runs as a hidden follow-on action.
